## Search Console handoff

1. Open the URL-prefix property for https://usman-farooqi.vercel.app/ and verify using the HTML tag after deployment.
2. Submit https://usman-farooqi.vercel.app/sitemap.xml.
3. Inspect the homepage and request indexing. Check Google's selected canonical after crawling.
4. Review query impressions, clicks and indexing status after enough data accumulates. Deployment and a sitemap do not guarantee indexing or ranking.

An HTML meta tag verifies a URL-prefix property. A Domain property requires DNS verification. No Search Console account actions were performed in this task.
